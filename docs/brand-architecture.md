# LottoMind Brand Architecture

LottoMind is the master consumer brand and account ecosystem.

| Name | Role |
| --- | --- |
| LottoMind | Main brand, account, identity, credits, and access ecosystem |
| LottoMind App | Core number journal, Dream Oracle, Radar, wallet, news, and membership product |
| LOTTOMINDED ULTRA | Premium creative web experience and cinematic music-technology hub |
| Beat2Lotto+ | Beat-to-number and prompt feature |
| LottoMind Studio | Music workstation |
| LottoMind Arcade | Games and playable browser experiences |
| Guardian Collection | Physical merchandise and collectibles |

Robot RAHBEE, Static Wav, individual games, and other named experiences remain features within LottoMind Arcade or LOTTOMINDED ULTRA. They are not separate parent brands.

Existing route names and the established header order remain unchanged until a separately reviewed information-architecture migration is approved. Copy and metadata should use the role names above without changing account, entitlement, checkout, or redemption contracts.

## First-Use Principle

The first guest session is action-based, not timed. A visitor chooses a goal, completes one short interaction, receives a local result, and can create an account to keep connected results. Guest results never claim verified credits or server persistence.

Free allowances are three Dream Oracle entries, ten creative number sets, five saved items, three Prompt Lab generations, two premium game missions, and one Studio export preview. Paid entitlements remain controlled by the connected account service.
