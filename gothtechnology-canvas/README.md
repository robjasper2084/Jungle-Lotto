# GOTHTECHNOLOGY

Original HTML5 Canvas fighting game built for LottoMind Arcade.

## Build

- Entry: `public/gothtechnology-canvas/index.html`
- Runtime: plain JavaScript modules under `public/gothtechnology-canvas/src`
- App route: `/gothtechnology`
- Static asset root: `/gothtechnology/assets/GOTHTECHNOLOGY_EXPANDED_SPRITE_PACK_V2`
- User sheet root: `/gothtechnology-canvas/assets/user-sheets`

## Modes

- Arcade match: KALYX vs MASTER EZRA, best of three, 99-second rounds.
- Training: timer stays available while health and meter recover.
- CPU toggle: Master Ezra can be local player two or CPU.
- Debug: hitboxes and runtime diagnostics.

## Notes

The game uses only supplied custom assets and generated WebAudio tones. It does not include or copy any Capcom, Street Fighter, Activision, Atari, or third-party copyrighted game content.
