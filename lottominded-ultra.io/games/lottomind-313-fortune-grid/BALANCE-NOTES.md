# Balance Notes

All 24 fictional ventures use a synthetic three-step cost curve unrelated to actual real-estate value. Networks share the same three-venture size. Costs rotate evenly within every network (140/160/180 Detroit Dollars), and base Collaboration Fees rotate evenly (28/35/42).

Unique network bonuses change decision texture rather than declare a district socially superior: preview/control, route flexibility, rhythm rewards, upgrade efficiency, recurring income, Signal combinations, trade flexibility, and Legacy progress.

The automated suite runs 1,000 seeded Quick 313 matches, rejects deadlocks, impossible phases, non-finite or negative balances, and a broad network-completion imbalance. Standard play still needs longer human balance sessions before Beta approval; CPU personalities use intentionally readable heuristics, not hidden advantages.
