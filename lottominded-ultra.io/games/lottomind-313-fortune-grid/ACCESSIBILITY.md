# Accessibility

- All setup, roll, movement, venture, portfolio, Signal, settings, card, and results actions are semantic DOM controls.
- Roll, movement, fees, cards, Signal changes, score changes, and turn changes are announced through a polite live region.
- Visible focus indicators and 44 CSS-pixel minimum controls are provided.
- Districts have text labels plus eight symbols/pattern names; color is never the sole identifier.
- Settings include reduced motion, particles, high contrast, mute, and three text sizes.
- Camera supports keyboard pan (arrows/WASD), overview (`0`), pointer/touch drag, wheel/trackpad zoom, follow, and overview buttons.
- Beat Studio has a no-audio visual mode and an untimed Finish control. Audio never autoplays.
- Cards include screen-reader art descriptions. Icons use text equivalents or empty alt text when decorative.
- Mobile uses a stacked board/HUD layout with viewport-safe controls.

Known Beta limitation: two-finger pinch is delegated to browser/trackpad zoom behavior; dedicated multi-pointer pinch math remains a Phase 2 refinement.
