# Accessibility implementation and limits

Semantic landmarks and headings, labeled inputs, visible keyboard focus, a skip link, native dialogs with Escape closing and focus restoration, keyboard-contained dialogs, descriptive image alternatives, and accessible status messages are implemented. Search Escape explicitly closes the dialog rather than merely clearing the search field. No actions depend only on hover.

The selected desktop reference uses compact typography and controls. Mobile switches to stacked sections and two-column equipment tiles, with 44px primary actions. Desktop compact product actions retain at least 24px target height. Layout is checked at 320, 360, 390, 428, 768, 1024, 1440 and 1920 pixels; the reference-width image is checked at 864 pixels.

System reduced motion wins over local preferences. Static artwork remains when motion is reduced, data-saving is active, WebGL is absent or context is lost. Store sound starts off and requires an explicit action. The silent film is requested explicitly, has controls, can be skipped, and includes a visible text description. It does not block shopping.

Experience controls are in an expandable footer section. Browser zoom and product-image zoom are available. No scroll trap is introduced around the game; ordinary page navigation remains available.

This is implementation and browser QA evidence, not an accessibility certification. A full screen-reader audit and a production accessibility review with the final content are still required.
