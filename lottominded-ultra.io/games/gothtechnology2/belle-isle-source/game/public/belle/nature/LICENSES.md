# Belle Isle nature assets

Tree forms generated offline using Sapling Tree Gen 0.3.7 for Blender. Extension code is GPL-3.0-or-later per its manifest; original notices are retained under authoring/nature-sources/sapling_tree_gen. No extension code ships in the game runtime.

Tool: https://extensions.blender.org/add-ons/sapling-tree-gen/

The following photographic models/textures are CC0 from Poly Haven. They are adapted into lower-detail game models and texture atlases.

- Rock Moss Set 01 — Kless Gyzen: https://polyhaven.com/a/rock_moss_set_01
- Grass Medium 01 — Rob Tuytel, Rico Cilliers: https://polyhaven.com/a/grass_medium_01
- Dandelion 01 — Rob Tuytel, Rico Cilliers: https://polyhaven.com/a/dandelion_01
- Periwinkle Plant — Amal Kumar: https://polyhaven.com/a/periwinkle_plant
- Tree Small 02 — Rico Cilliers: https://polyhaven.com/a/tree_small_02
- Pine Tree 01 — Rob Tuytel, Rico Cilliers: https://polyhaven.com/a/pine_tree_01
- Bark Brown 02: https://polyhaven.com/a/bark_brown_02

License: https://polyhaven.com/license

Tree Small 02 and Pine Tree 01 supply foliage textures only; their original high-polygon tree models are not bundled in the game. Planting and tree forms are an artistic reconstruction, not a botanical survey of Belle Isle. Source hashes and transformation notes are retained in the project research directory.
