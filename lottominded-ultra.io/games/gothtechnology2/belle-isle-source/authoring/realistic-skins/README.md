# Higgsfield material pass

17 successful source textures generated on 2026-11-03 through Higgsfield (Nano Banana Pro returned nano_banana_2; Seedream 4.5). Runtime color maps are 1024 square, relief/roughness detail maps 512 square, water normal 512 square. Six source images were replaced after visual rejection of unwanted paving grids or borders. The processor crops useful material regions, suppresses uneven source illumination, blends opposite edges and derives restrained detail from luminance; these are not scanned PBR measurements.

The original hero, dog, bike and camera base-color atlases, UVs, skeletons and moving parts remain intact. Runtime model-space detail adds cloth weave, skin pores, short fur, machined metal and rubber grain. Buildings, ground and vegetation use material-specific color/detail. Water retains all reactive wave physics with the generated normal detail.

Three Meshy retexture jobs failed; their output was not used. The original face and coat markings are preserved. Conservative total quoted project submissions: 121.75/200 credits, including unsuccessful jobs (refunds not presumed). See higgsfield-budget.json in the hero-hoverbike authoring folder for accounting.
