# Poly Haven environment asset intake — draft only

This branch records the exact 11 unique uploaded archive contents (12 ZIPs including one duplicate tree). The source fingerprints were computed from every uncompressed archive member, not ZIP metadata. Each asset has an official CC0 source URL. No source archives are committed. Source files were authored in Blender 2.93–4.04; six packages have named author LODs.

The first opaque review batch exports twelve variants across three texture tiers: Barrel 02 (1), Dry Branches Medium 01 (3), Dead Tree Trunk 02 (1), Namaqualand Boulder 03 (1), Rock Moss Set 01 (6). Source acquisition uses the documented Poly Haven API with a Digital Static User-Agent, checks each download and refuses any mismatch with the uploaded source fingerprint. Blender is installed on the Actions runner, not the user's machine. Texture reduction and decimation are **lossy**. Keep original sources; do not call the resulting derivatives lossless. Alpha-tested foliage and fence assembly, and the tree Geometry Nodes scene, are explicitly deferred; no whole-scene imports.

The optional preview build selects the 1K/600-triangle boulder and two moss variants and uses the existing mapped boulder placements, unchanged six draw pools, same quality-distance limits, and unchanged terrain/collision registration. Only High quality near rocks are replaced; automatic and smooth and all far silhouettes remain as before. Geometry is fitted to the existing registered collision radius and height. In the normal build, the flag is off and no preview asset is loaded. No new positions for industry or trees are fabricated.

The workflow produces a review artifact, not production assets or a deployment. The screenshot job uses the real game gallery with a proof that at least one captured visit has active review rock instances. Software screenshot evidence does not establish photorealism, exact framing, or physical-device performance. Require matched baseline/candidate screenshots, visual inspection (including exact rock material and habitat suitability), collision/race checks, existing native desktop/mobile performance, and Pages size gates before any promotion. The gate does not weaken existing checks. Branch is separate from Cadillac and cinematic releases. The public Poly Haven library is CC0; use source attribution in project notices for provenance.
