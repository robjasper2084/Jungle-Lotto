# Underground popup bundle

This is the Underground runtime selected by the owner's Robot RAHBE Arcade URL (`?game=underground`), copied on 2026-09-08 from `_robot_rahbe_arcade_work/lottominded-ultra.io/games/robot-rahbe-underground`. Its required `robot-rahbe-arcade/shared/{input,core,rahbe-core}.js` files are included alongside it. Game source, artwork, and Phaser license files are preserved.

The New Drop feature loads this portable bundle only after Play is selected. The existing title screen provides Begin Descent, Continue, sound and field-guide controls. The surrounding storefront popup handles loading, retry, focus, Escape, and removing the iframe on close. Sound starts off. Saves stay on the current site's origin; existing localhost:8170 progress is not copied or changed.

The New Drop reward section launches five games: Underground, Robot RAHBE / Shadow Ops, Vault Rush, GOTHTECHNOLOGY Fighter, and 2084 Static WAV. Static WAV uses the existing sibling `../opengw-levels/` route and shared reward tracker. Game Grid resolves its launches through the same registry, so Play, popups, and standalone links use the same reward-enabled routes. Shadow Ops and Vault Rush runtime source and assets were copied from `_robot_rahbe_arcade_work` on 2026-09-08, together with their shared arcade dependencies. The original source checkout is untouched. Source-game updates must preserve the reward hooks, local storefront links, and common dependencies, then pass the desktop/mobile browser tests.

Storefront customization: the opening screen uses `../../media/underground-armory-campaign-v1.webp`, shared with the New Drop feature. The final title-screen rules in `robot-rahbe-underground/style.css` supply responsive framing and text contrast. Preserve these rules when refreshing the source-game bundle; gameplay environments still use their original artwork.

The shared score discount preview uses 10,000 / 25,000 / 50,000 / 100,000 cumulative points for 5% / 10% / 15% / 20%. Underground, Shadow Ops, Vault Rush, and Static WAV contribute their native scores. A completed GOTHTECHNOLOGY match with at least 30 active seconds and player actions contributes 2,500 points, or 5,000 for a win; training, debug play, and replays are excluded. Opening a title screen awards nothing. Static WAV keeps one run ID across pause/resume and creates a new ID for each new run; menu/reset transitions flush the final score before replacing it.

`arcade/rewards.js` stores one high-water score per game and run ID in `gothtechnology.arcade.discount-preview.v2`. Only score increases count on repeated reports or resumed runs; distinct new runs add points. Web Locks serialize browser writes across tabs. The old Underground best reward is carried forward once, with its saved checkpoint used as a baseline to prevent counting it twice. Blocked storage falls back to the current page session and the UI reports that limitation. `reward-tracker.js` connects standalone game pages, while the popup also captures progress on close. Product and loadout comparisons use the same cumulative total. Progress is local to one browser origin; another port, domain, or device has a separate save.

This is explicitly a non-redeemable local preview. No coupon is issued and no provider/cart total or checkout is changed by the game.
