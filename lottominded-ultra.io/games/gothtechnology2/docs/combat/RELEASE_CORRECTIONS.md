# Release corrections

Final packaging uses the separately packaged original Elmwood source in elmwood-source, including its existing online rooms, rider choices and latest mobile resize fix. Building the older external euc-detroit-riverwalk directly would omit those existing features. That external source now has the compiled input adapter and Royale entry too, and passes its typecheck; broader source synchronization is not claimed complete. No old Swoop-embedded cemetery is used.

The 36.75-second City in Motion movie is encoded at the same 1280x720 with H.264 and AAC sound, fast-start metadata, reduced from 17,151,250 to 3,385,726 bytes. The original remains in Git history and the private build directory. This brings the Pages artifact below its limit without removing playable modes or films.

New requests for all-player voice and additional Swoop mode parity are follow-up work, not claimed in this release.
