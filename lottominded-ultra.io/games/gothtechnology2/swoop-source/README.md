# Digital Static Ride

Independent riding controller, camera and custom character motion for the Detroit level.

Use npm run check, npm test, and npm run build. The build output is dist/. From the asset pack root, scripts/install_detroit_v05.py installs the current game at /detroit/detroit.html. See ../../docs/Ride_Detroit_Workflow.md.

Runtime dependencies are Three.js and Rapier. Their license notices are included in the installed build's licenses/ directory.
