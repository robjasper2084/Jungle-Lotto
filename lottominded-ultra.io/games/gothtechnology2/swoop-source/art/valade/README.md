# Valade / Atwater reference reconstruction

Original Blender 5.2.1 models created for this local Swoop update. Editable .blend and FBX masters accompany lightweight GLB runtime files.

Road, park, inlet, building and barge footprints follow public OpenStreetMap reference data, retrieved 2026-10-03. © OpenStreetMap contributors, ODbL 1.0. The snapshot and preparation script preserve provenance. Google Maps satellite and Detroit Riverfront Conservancy photographs were used for visual study only; no Google or Conservancy image tiles are shipped.

References: https://www.detroitriverfront.org/plan-your-visit/parks-greenways/robert-c-valade-park and the user-supplied Valade Google Maps pin. Models include The Shed and open terrace, green/yellow play towers, rope bridge, Bob's Barge, Adirondack chairs, outdoor chimes, picnic tables and barbecue. Beach outline, architectural height, finishes and individual furniture positions are approximate visual reconstructions, not a survey. Camera poles are decorative original assets and do not capture or transmit images.

Regenerate with scripts/prepare_valade_site.mjs then Blender scripts/build_valade.py and scripts/optimize_street_valade.mjs. FBX is provided for engine authoring; a Unity import has not been verified for this update.
