# LOTTOMINDED ULTRA Brand Page

This folder is a standalone static brand page for the music app.

- Local route: `lottominded-ultra.io/`
- Studio app link: `../lottomind-stem-studio/index.html`
- Web App preview: use the Website/Web App switch to open the studio inside the branded page.
- Mobile preview: toggle Mobile View to reshape the embedded studio into a phone-style frame.
- Branded hero art: `assets/brand/generated-cinematic-hero.png` plus the local LM reference assets.
- Remotion intro: the homepage embeds the local logo sting render from `../lottomind-motion-intro/`.

The page uses local brand assets only. No backend, paid API, cloud upload, or third-party copyrighted media is required.
