# Public Site

The repository now has a root static landing page so visitors can open the project from a public GitHub Pages URL.

## Public Routes

- Home: `https://robjasper2084.github.io/Jungle-Lotto/`
- Studio app: `https://robjasper2084.github.io/Jungle-Lotto/lottomind-stem-studio/`
- Brand page: `https://robjasper2084.github.io/Jungle-Lotto/lottominded-ultra.io/`

## GitHub Pages Setup

1. Push this repository to GitHub.
2. In GitHub, open repository Settings.
3. Open Pages.
4. Set Source to deploy from the `main` branch and `/root`.
5. Use the root landing page and studio app route for public sharing.

The site is static and uses local assets only. No backend, cloud upload, or paid API is required.
